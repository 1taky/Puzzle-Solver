## Вимоги

* **Java Development Kit (JDK):** версія 25
* **IDE:** IntelliJ IDEA

---

## Як запустити в IntelliJ IDEA

1. **Відкрийте проєкт:**
   * Запустіть IntelliJ IDEA та оберіть **File** ➔ **Open...**
   * Оберіть головну папку проєкту **`Puzzle Solver`**.

2. **Перевірте Sources Root:**
   * Переконайтеся, що папка `src/main/java` або `src` підсвічується синім кольором.
   * Якщо ні: натисніть правою кнопкою миші на **Папку** ➔ **Mark Directory as** ➔ **Sources Root**.

3. **Запустіть програму:**
   * Відкрийте файл `src/main/java/solution/PuzzleSolverInterface.java`.
   * Натисніть зелену стрілку **Run** поруч із кодом (або натисніть `Shift + F10` / `Ctrl + R` на Mac).
